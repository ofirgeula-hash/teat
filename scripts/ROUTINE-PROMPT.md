# Every-2-days task report by email

The report itself is generated by `scripts/task-report.mjs`. Delivery is driven by a
Routine created from the claude.ai Routines UI (a Routine created from inside a Claude
Code session gets no Gmail connector and silently fails to send).

- Schedule: every 2 days, 08:00 Israel time
- Recipient: Ofirgeula@gmail.com

Paste the prompt below into the Routine, with the Gmail connector enabled.

---

Send Ofir the "קניות ומשימות" summary report by email. Do the whole thing in one turn and
do not ask any questions.

**If you can run shell commands** (a Claude Code session with the `teat` repo):
1. `cd` into the `teat` checkout, then
   `git fetch origin claude/shopping-tasks-project-i1crls && git checkout claude/shopping-tasks-project-i1crls`
   (if that branch is gone, the script is already on the default branch).
2. `node scripts/task-report.mjs /tmp/task-report.html` — the one line it prints on stdout
   is the email subject; use it verbatim.
3. `cat /tmp/task-report.html` and send that HTML unchanged.
4. Do not commit or push anything.

**If you cannot run shell commands**, build the report yourself from these two public
Firestore REST endpoints (no credentials needed):

- items: `https://firestore.googleapis.com/v1/projects/shopping-list-db6a8/databases/(default)/documents/items?key=AIzaSyB-sa9xR6DxdYv6DCAUn1Ze1Kzb6TMuxzA&pageSize=1000`
- stores: `https://firestore.googleapis.com/v1/projects/shopping-list-db6a8/databases/(default)/documents/stores?key=AIzaSyB-sa9xR6DxdYv6DCAUn1Ze1Kzb6TMuxzA&pageSize=1000`

Data model — each item has `text`, `done`, `urgent`, `storeId`, `listType`, `order`.
A missing `listType` means `shopping`. Each store has `name` and `order`.

Report contents (Hebrew, RTL, `dir="rtl"`, one 600px column, white cards on `#eef2f7`):
1. Title "דוח משימות" and today's date in Hebrew.
2. A row of three numbers: open items, urgent open items, items completed in the last
   2 days (`updateTime` within 48h).
3. "משימות אופיר" — open items with `listType: "ofir"`.
4. "משימות ירין" — open items with `listType: "yarin"`.
5. "רשימת קניות" — open `shopping` items grouped by store (stores sorted by `order`
   ascending, items by `order` descending), each group headed by the store name and count.
   Items whose `storeId` matches no store go under "ללא חנות".
6. "הושלם ביומיים האחרונים" — the recently completed item names, comma-separated.

Skip items where `done` is true (except in section 6). Within every group, urgent items
come first, marked with a red `!` instead of the grey bullet, in red bold.

Send with the Gmail tool:
- to: `Ofirgeula@gmail.com`
- subject: `דוח משימות · DD.MM.YYYY · N פתוחות, M דחופות` (drop the last part if M is 0)
- htmlBody: the report HTML
- body: a plain-text version (headings, then `• item` lines, `!` for urgent) as fallback

Send exactly one email. If the data cannot be fetched, retry once, then send a short
Hebrew plain-text email saying the report failed and include the error.
